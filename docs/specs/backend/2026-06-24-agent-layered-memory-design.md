# Agent 分层记忆系统设计

- 类型：后端 spec
- 日期：2026-06-24
- 状态：已实现（经验记忆随 Phase C 落地，见 [C4](2026-06-27-v3-phase-c4-experience-memory-design.md)）
- 关联：[V3 路线图](../architecture/2026-06-24-v3-roadmap-design.md) · [C4 经验记忆](2026-06-27-v3-phase-c4-experience-memory-design.md)

## 问题与目标

agent 记忆要能筛选、总结、遗忘、强化、更新，而不是堆聊天记录。本文定义分层映射、主记忆与经验记忆隔离、巩固时机、三级分化与防伪经验卫生。原始日志复用事件时间线，不另建平行库。

## 决策

| 决策点 | 选择 | 否决项 | 理由 |
|---|---|---|---|
| 情景记忆 | 既有 event log | 新建记忆库 | append-only + hash 链已是真相源 |
| 经验记忆 | 独立子系统 | 并入主记忆 | 可整体清空/降权，防污染事实 |
| 写权限 | 经验仅次 agent 提炼后写 | worker 随手写 | 降噪 |
| 生效 | `crossTaskLearning` 开关，默认 off | 默认开 | 伪经验风险 |
| 巩固时机 | 任务边界异步 | 执行中途 | 离开关键路径 |
| 记忆形态 | 事件日志的投影（带回链） | 无出处摘要 | 可重算、可纠偏 |

## 设计

### 分层映射

| 层 | 存储 | 归属 | 写 | 读 |
|---|---|---|---|---|
| 情景 | 事件时间线 | 既有 | 系统 | 巩固回放 |
| 语义 | 事实库 | 主记忆 | worker（`memory` 工具） | worker |
| 偏好 | 偏好库 | 主记忆 | worker / 用户 | worker、planner |
| 程序 | 经验库 | 经验记忆 | 仅次 agent | planner |
| 风险 | 风险库 | 经验记忆 | 仅次 agent | planner + 权限层 |
| 反思 | 反思缓冲 | 经验记忆 | 次 agent | 巩固后丢弃 |
| 风险显著度 | 标记 | 横切 | 次 agent | 检索权重 + 权限 |

主记忆（事实/偏好）与经验记忆（程序/风险/反思）目录与信任级分离。主记忆高信任；经验是带置信度的启发。

### 巩固与三级分化

次 agent 在任务边界回放事件 → 写反思 → 将反复有效的提炼为程序/风险 → 打分定级。

| 级 | 含义 | 检索权重 |
|---|---|---|
| T1 核心 | 高置信、近期反复有效 | 强 |
| T2 候选 | 中置信/中等老化 | 中 |
| T3 观察 | 低置信/偏旧/未验证 | 弱 |
| 低于 T3 | 过低/过旧/屡误导 | 删除 |

`score = f(置信度, 距上次强化, 验证次数)`，阈值 T1/T2/T3 与实现常量以 `src/core/memory/experience-*.js` 为准（配置默认 0.7 / 0.4 / 0.2）。被采纳且后续审核有效则强化升级；误导或与新事实冲突则削弱；久未强化则衰减下沉。同类经验按 cue 相似度聚簇归并，写时重算等级，跌破 T3 删除并留日志。

### 自主优化两层

任务内：审核摘要立刻改后续派发（始终开）。跨任务：提炼进经验记忆，供后续 planner（`autonomy.crossTaskLearning`: `off` | `on` | `gated`，默认 `off`；gated 高影响经验需人工确认）。

### 卫生与原则

三级分化 + 末位淘汰、置信老化、去重与总量上限、回链可追溯、经验可一键清空、检索合成简报而非贴原文。风险记忆显著度可把权限 allow 单调升为 ask（见 `risk-rules.js` 的 `escalate_only`）。`reasoning_content` 不作长期记忆，只存提炼后的判断摘要。

检索实现：`experience-retrieval.js` 按 cue 重叠 × tier 权重取 top-k；风险 cue 单独收集驱动权限升级。

## 边界与不变量

1. 经验可删，事实与原始日志不动。
2. 经验默认不生效，需显式开关。
3. 记忆是投影，必须可回溯 source task/turn。
4. 不把 `reasoning_content` 原文写入记忆。

## 与现状的差异

存储 schema 与常量以 `src/core/memory/`、`src/config.js` 的 `orchestration.experience` 为准。Phase C 落地细节见 [C4](2026-06-27-v3-phase-c4-experience-memory-design.md)。

## 验收

经验读写仅在开关打开时影响派发；风险 cue 能触发权限升级；跌破 T3 被删除；清空经验不影响主记忆与时间线。入口 `npm test`。
