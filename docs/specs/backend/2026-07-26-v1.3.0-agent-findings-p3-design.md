## 问题与目标

三项：shell 命令级策略（高危确认 + 禁止硬拒，双层）；语义降级可观测并删除空转 `languages` 键；删除 GUI 休眠 UMD 渲染层。#9.3 与 #10 继续挂账。不动 `agent-runtime` 行为路径。

## 决策

| 决策点 | 选择 | 否决项 | 理由 |
|---|---|---|---|
| 命令策略 | 双层：引擎升类 + `runProcess` 禁止兜底 | 只做引擎层 | test 嵌套执行不过引擎 |
| 包装 shell | 一律 dangerous | 拆 `-c` 字符串 | 无管道场景下主走私面是包装 shell |
| full-auto | 高危仍 ask | 放行 | 危险动作不自动 |
| 清单 | 硬编码 | 用户可配 | 保守起步 |
| languages | 删除空转键 | 让引擎消费 | 文档/配置与代码对齐 |
| 休眠层 | 整目录删除 | 继续维护第 4 份 | 已漂移且无测试覆盖 |

## 设计

### 命令策略

`src/security/command-policy.js` 的 `classifyCommand(argv) → safe|dangerous|forbidden`。归一化 basename、小写、剥可执行后缀，部分规则看后续 argv（如 `git push --force`）。

第 1 层：shell/git 的 `resolveCategory` 把 forbidden 映射 `destructive`（硬拒且不可被审批缓存放行），dangerous 映射 `execute_dangerous`（全档 ask），safe 仍 `execute` / git read 仍 `read`。

第 2 层：`runProcess` spawn 前拦 forbidden，不 spawn；dangerous 不在此层拦（避免打断 test 的 `cmd.exe /c` 验证回路）。

清单要点：forbidden 含 `format`/`mkfs*`/`diskpart`/`bcdedit`/`dd`；dangerous 含删除与系统命令、包装 shell（bash/sh/cmd/powershell/pwsh）、解释器执行参数（`node -e`、`python -c` 等）、`npm publish`、`git push --force` 等。

审批 summary 加截断 argv 预览；修 `event-contract.argHint` 读 `call.params` 并支持 `argv`。

### 语义降级可观测

`semantic-engine` 在 degraded 翻转处发一次 `context:semantic_degraded { reason }`，注册进 `SESSION_EVENT_TYPES`，`event-contract` 出非静默 warn。删除 `context.semantic.languages` 与 `normalizeLanguages`；老配置键静默消失。语言固定 js/ts/py。删除未使用的 tsx wasm。

### 休眠渲染层

删除 `gui/renderer/`。`gui/main.js` 顺序改为 dev URL → `renderer-dist`，两者皆无则报错退出并提示先 `npm run build:renderer`，不自动构建。删对应 2 个单测；`npm run check` 同步。

## 边界与不变量

1. 内核公开 API、审批 `decisions`、事件顺序不变。
2. 回滚链与 change-store 不变。
3. 不做命令策略用户配置、「总是允许」持久化、包装 shell 内嵌串扫描。

## 验收

高危命令 auto/full-auto 需确认；禁止命令硬拒且缓存不可放行；test/git 回路零回归；降级事件 exactly-once；老配置不炸；未构建 GUI 报错清晰。入口 `npm test`、`npm run check`。
