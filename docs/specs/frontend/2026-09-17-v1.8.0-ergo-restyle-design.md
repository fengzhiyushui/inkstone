# v1.8.0 工学换肤设计

- 类型：前端 spec
- 日期：2026-09-17
- 状态：已实现
- 关联：[实施 plan](../../plans/frontend/2026-09-17-v1.8.0-ergo-restyle-plan.md) · [v1.4.0 定稿](2026-07-28-v1.4.0-frontend-redesign-design.md) · [v1.8.1 壳层](2026-09-20-v1.8.1-dsh-shell-design.md)

## 问题与目标

换视觉语言，信息架构不动。10 套主题从「5 暗 5 明双峰」重编为暗 → 柔暗 → 柔明 → 明四段带；卡片改两段式；composer 柔光；主题中枢。DOM 与类名冻结，γ 分层落地，β 重建路径留给后续。

## 决策

| 项 | 结论 |
|---|---|
| 主题数量 | 保持 10 套 |
| 明暗分布 | 填中间过渡，不做「真正的中灰」 |
| 落地路径 | 先 γ 分层，β 留 v1.8.x/v1.9 |
| 氛围层 | 不做粒子；舒适靠留白/圆角/柔光/字阶/对比度 |
| 继承 v1.4 | 状态入 `.cz-meta`、侧栏三段、指标 5 形态、kernel 零改动、lucide、zh/en |
| lastLight 默认 | `latte` |
| 时间线抽屉 | 延后 v1.9.0 |
| 蓝图网格 | 不做 |

## 设计

对比度闸门 ≥7:1 决定底色亮度有物理死区：L 90–164 之间白字与墨字都做不到 7:1。过渡主题只能从两侧向死区边缘延伸：

| 档 | 亮度带 | 套数 |
|---|---|---|
| 暗 dark | L 25–51 | 3 |
| 柔暗 dim | L 55–89 | 2 |
| 柔明 tint | L 165–235 | 2 |
| 明 light | L 236–251 | 3 |

主题集：保留 `sumi`/`nord`/`latte`/`paper`；新增 `slate`（Tokyo Night Storm）、`vesper`、`ash`（Zenburn）、`snow`、`sand`、`lotus`；退役 `forest`/`dawn`/`mocha`/`moon`/`clay`/`rose`。旧 id 经 `LEGACY_THEME_MAP` 静默迁移（`workbench-state.js` 等三处）。

对比度闸门升级为常驻：`scripts/check-theme-contrast.mjs` + `tests/unit/gui/theme-contrast.test.js`，亮度实现单源 `gui/src/state/contrast.js`。阈值：正文/画布与正文/面板 `[7, 19.5]`；次级 ≥4.5；弱化/强调/语义 ≥3；按钮文字 ≥4.5；描边 ≥1.5。

四档只是展示分组；代码明暗判定仍二元（`dark|dim → dark`，`tint|light → light`）。`themes.js` 保留 `tier` 与 `group`，`isLightTheme()` 语义不变。设置 › 外观按四段分组。

舒适性：正文对比上限 19.5；字阶不出现 <11px；卡片圆角 10–14px；柔光只在 focus-within 与 hover；玻璃态只给浮层，`blur ≤ 12px`，偏好 `glass`；动效 ≤ .25s 且尊重 `prefers-reduced-motion`。

视觉采纳原稿：卡片等宽头部 + 正文两段式、composer 焦点柔光、主题选择器分段胶囊、五色块 + hex + 实测对比度详情、新会话分体按钮、时间戳常显淡色。改造：遥测条并入 `.cz-meta`；思考链改为推理摘要卡（purpose/model/推理 token，默认折叠）。放弃：48px 遥测条、常驻五色横幅、品牌字样、无源指标、粒子、`transition: all`。

实施 γ 分层：P0 tokens 地基 + 闸门 + TUI 调色板；P1 壳层视觉；P2 卡片两段式 / 首页 / 设置›外观 ThemeHub / 推理摘要卡（`event-contract.js` 加 `thought` kind）；P3 截图基线与收口。每层五项准入：`npm test` 只增不减、`npm run check`、`build:renderer`、`gui-smoke`、kernel 路径 diff 为空。

冻结清单：`<html theme="id">`、18 槽位名、10 个 `[theme]` 块、smoke 选择器、`.rail-fn` 顺序、`.cz-meta` 5 形态、`.shell.shell-settings`、30px 标题栏、`.sn-backdrop`。

β 留门约束：不新造冲突类名；`shell.css` 新规则追加末尾独立区块；派生变量进 `theme.css`；组件不新增 props 契约；偏好键 `lastDark/lastLight/glass` 一次定名。

## 边界与不变量

- 任何 `src/core` 改动不做。
- 时间线抽屉、粒子、编辑器、FIM、导出 JSONL、分叉 Turn、单条 rollback、15 套主题、主题在线安装均非目标。
- v1.7.2 前置缺陷（assistant 回复入流、usage 刷新、`.sn-*` 变量）由该补丁处理。

## 与现状的差异

v1.8.1 已走 β：壳层结构色改为明暗两档中性阶梯，10 主题 id 只保留 accent/语义槽。四段带概念退场，`tier` 仅作设置页分组标签。闸门口径改为结构 2×7 + accent 10×4。本文的对比度单测、ThemeHub、推理摘要卡、偏好键仍有效。
