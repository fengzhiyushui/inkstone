# v1.8.1 壳层重构（DSH 参照 · β 路径）

- 类型：前端 spec
- 日期：2026-09-20
- 状态：已实现
- 关联：[v1.8.0 β 留门](2026-09-17-v1.8.0-ergo-restyle-design.md) · [v1.4.0 定稿](2026-07-28-v1.4.0-frontend-redesign-design.md) · [post-V3 路线图](../architecture/2026-09-17-post-v3-roadmap-design.md)

## 问题与目标

把壳层从「单列 + 全窗设置」改成「三列可拖拽 + 右侧 dock + 模态设置」，视觉从色相主题改成中性蓝灰加单一品牌蓝。信息架构（项目分区、会话卡、状态行、敏感提醒）全部保留。参照 DSH 的设计事实，不引用其代码。

版本按规则本应 minor（v1.9.0），因路线图已占用该号，落地称 v1.8.1；界面版本显示以 `App.jsx` 的 `VERSION` 为准（当前 1.8.6 行）。

## 决策

| 项 | 结论 |
|---|---|
| 平台 | 仍是 Electron 桌面壳，换布局与视觉 |
| 路径 | 走 v1.8.0 预留的 β 标记重建 |
| 主题 | C 变体：结构槽走 DSH 明暗两档；10 主题 id 只贡献 accent/语义 8 槽 |
| 设置 | 全窗改模态 |
| 右栏 dock | 文件树 + 改动 + 恢复三面板全做 |
| 对话/轨迹 tab | 现在做壳，数据源后续换契约 |
| 移植原则 | 全量搬设计数值，零引用 DSH 代码，Inkstone 原生重写 |
| 图标 | 继续 lucide，不搬内联 SVG 体系 |

不做：粒子/网格、命令面板、分叉 Turn / 消息评分、右栏内置浏览器、macOS vibrancy、多级工作区树。

## 设计

壳层：三列 grid + 拖拽 handle + 右栏可收。列宽常量见 `gui/src/state/columns.js`：

| 常量 | 值 |
|---|---|
| `SIDEBAR_MIN` / `MAX` / `DEFAULT` / `COLLAPSED` | 264 / 420 / 280 / 56 |
| `SIDEBAR_AUTO_COLLAPSE` | 1024 |
| `RIGHTBAR_MIN` / `MAX` / `MAX_RATIO` / `DEFAULT_RATIO` | 300 / 1600 / 0.7 / 0.45 |
| `CENTER_MIN` | 400 |

`computeColumns` 纯函数求解。

视觉 token：中性蓝灰阶只分明暗。结构槽 10 个（`bg-base/panel/element/inset`、`text/mut/faint`、`border/border-strong`、`code-bg`）两档逐字节相同；10 主题各定义 `accent/hover/soft/text` 与 `ok/warn/err/info`。见 `gui/src/styles/tokens.css`。闸门 54 项（structure 2×7 + accent 10×4）。

组件：`AppFrame.jsx` 三列 + `DragHandle`；`Rail.jsx` 侧栏（新会话、功能区、搜索、项目树、设置）；`ChatView` / `HomeView`；`Composer`；`Dock.jsx` 四 tab（plan/files/changes/recovery）；设置模态 `Settings/`。类名沿用 `.rail-*` `.cz-*` `.ev-*` 等，CSS Modules 用于新组件。

会话页：用户气泡右对齐限宽，助手正文无气泡，思考折叠，composer 卡 + stats 行（状态仍在 composer 内）。`chatTab` 支持对话/轨迹。

右栏 dock：`role=tablist/tab`，面板槽 + 关闭钮。文件树接 `listTree`/`readFile`；改动接 `ChangesPanel`；恢复接 `RecoveryPanel`。

主题 C 变体实施：B0 壳层骨架 + 原生 overlay 标题栏；B1 token 重铺；B2 侧栏 + 会话页；B3 右栏 dock；B4 设置模态 + 重做 `dom-contract` / smoke 基线。

代码纪律：

1. `gui/package.json` 不得新增 `@deepseek-ai/*`；守卫测试断言源文本无此类 import。
2. 不复制 DSH 源文件；每个新文件是 Inkstone 原生写法。
3. 18 槽 `tokens.css` 契约不变；DSH 派生量落 `theme.css` 别名块。
4. 文件头不标 DSH 来源。
5. CSS Modules 只对新建组件使用。

## 边界与不变量

- 信息架构、敏感提醒、审批语义、kernel 零改动红线保持。
- 偏好键 `lastDark` / `lastLight` / `glass` 沿用；新增 `sidebarWidth` / `rightbarWidth` / `rightbarOpen`。
- 三灯/状态行语义不因换皮改变。
- 密钥仍只见掩码。

## 与现状的差异

当前代码即本版落地形态：`App.jsx` 组 AppFrame/Rail/HomeView/ChatView/Dock/Settings；视图 `home|chat|projects|mcp|plugins`；dock `plan|files|changes|recovery`；主题 10 id 与 `LEGACY_THEME_MAP` 在 `workbench-state.js`。后续 patch 版本在细节与缺陷修复上演进。
