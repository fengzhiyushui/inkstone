## 1. 背景与目标

现有前端三端是 V3 支柱③逐阶段演进的产物:GUI 手写 VS Code 风格工作台、TUI claude-code 式行内滚动流。功能已全,但视觉语言是"做功能时顺手定"的,缺少一次以设计为主导的整体打磨。v1.4.0 的目标:**GUI 与 TUI 界面全部重做**,先出 HTML 设计稿、定方向,再进具体实现。

**非目标(本版明确不做)**:

- 不改 kernel / 内核契约 / 事件协议——纯展示层与 app 层重做,沿用既有数据流(`kernel.session.subscribe` → 事件派生 → 渲染)。
- 不动文档维护规范与项目总体流程(用户明示:不扩大对外部流程工具的依赖,但已定的流程不做大变动)。
- 不在设计稿阶段定实施技术栈(见 §2 决策 3);不做 CLI 重设计(CLI 输出面已在 D-G4 对齐)。

## 3. 设计系统(单一 token 源)

### 4.1 GUI 侧栏结构(第四轮重构骨架,第五轮细化项目区)

第三轮把功能入口(项目管理/MCP/插件/改动)放在会话列表**下方**的"工作区"分组里,被一长串会话挤到视线之外。第四轮按 Codex / Claude Desktop 的组织方式改为**三段固定分区**;第五轮进一步把"项目"从扁平列表改为**每项目一个独立分区,分区内挂该项目自己的会话**:

```
品牌 + 版本
[＋ 新会话  Ctrl N][⌄]        ← 分体按钮,⌄ 展开「在哪里新建」菜单
[搜索会话与项目…]
──────────────────────────
功能区(固定,不随列表滚动)     ← "上方为功能区"
  ⌂ 主页   ▦ 项目 4   ± 改动 7   ⬡ MCP 服务 2   ◈ 插件
──────────────────────────
项目                      ＋   ← 这个 ＋ = 打开新文件夹作为新项目
 ▼ ● deepseek-code  当前  ＋   ← 项目头的 ＋ = 在本项目中新建会话
     今天
       重构登录页组件      12:40
       修复 shell 环境变量泄漏 11:02
     昨天
       前端重设计 v1.4.0   18:22
       grep 超时预算实现   15:47
     显示全部 12 个会话 →
 ▶ ○ shop-frontend    5   ＋   ← 折叠态
 ▶ ○ api-gateway      3   ＋
 ▶ ○ notes            1   ＋
──────────────────────────
 ▼ 独立对话            3       ← 只放不属于任何项目的会话
──────────────────────────
高 gao                      ⚙
```

**要点**:

- 功能区 `flex: none` 固定在上方,只有"项目 + 独立对话"区滚动。
- **每个项目 = 一个 `.proj` 独立分区**:分区头(`.proj-h`,含展开箭头 / 状态点 / 项目名 / 会话数 / ＋)+ 分区体(`.proj-b`,带左侧竖引导线,内含该项目的会话,按今天/昨天/本周分组,超出部分收成"显示全部 N 个会话 →")。
- 当前项目默认展开并以 `--ok` 绿点 + `当前` 标签标识,其余默认折叠。
- **"独立对话"语义收窄**:第四轮它装的是全部会话,第五轮起只装**不绑定任何项目**的会话。

### 4.1.1 新建会话的项目归属(第五轮解决的核心问题)

用户诉求原文:「在该项目分区下可以自己去选择新建还是使用原来的对话,而且**不需要再重新指定项目文件夹**」。落点是三个入口:

| 入口 | 行为 | 是否需要选文件夹 |
|---|---|---|
| 项目头的 `＋` | 在**该项目**中新建会话,直接继承该项目目录与 git 上下文 | **否** |
| 分区内点任一会话 | 打开该项目下的**原有**会话 | 否 |
| 顶部 `＋ 新会话` | 在**当前项目**中新建(按钮 title 明示是哪个项目) | **否** |
| 顶部 `⌄` → 菜单 | 选新建位置:当前项目(默认高亮)/ 其他任一项目 / **独立对话**(不绑目录)/ **打开新文件夹…** | 仅最后一项需要 |

即:**只有"新增一个项目"时才会弹目录选择**,日常新建会话一律继承已有项目上下文。实施时对应 kernel 侧的 workspace root 由会话所属 project 决定,而非每次新建时询问。

### 4.2 对话框指标的 5 种形态(第四轮新增)

`.cz-meta` 行里,**比例型指标**(上下文用量 / 缓存命中率 / 检索命中率)按选定形态渲染;**状态型标签**(分支 / 检查点 / 连接 / 模型 / 主题 / 语言)恒为文字。

| 形态 | id | 呈现 | 适用 |
|---|---|---|---|
| 文字 | `text` | `tok 34.2k · 命中 38%` | 最省空间,窄窗口 |
| 数值 | `num` | `上下文 34.2k/128k · 缓存命中 38% · 检索命中 12/14` | 要看确切数字与分母 |
| 进度条 | `bar` | 细长条 + 百分比,超阈值转 `--warn` 色 | **默认**,一眼看占比 |
| 点阵 | `dots` | 十格方块填充 + 百分比 | 终端质感,与 TUI 呼应 |
| 关闭 | `off` | 不渲染任何指标 | 极简偏好 |

切换有两条路径:对话框内的形态按钮(点击轮换,临时试)、设置 › 状态显示(固定,写入偏好文件)。
