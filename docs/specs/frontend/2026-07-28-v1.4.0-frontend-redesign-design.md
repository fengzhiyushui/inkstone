# v1.4.0 · 前端界面重设计

- 类型：前端 spec
- 日期：2026-07-28
- 状态：已实现
- 关联：[实施 plan](../../plans/frontend/2026-07-31-v1.4.0-frontend-redesign-plan.md) · [v1.8.0 工学换肤](2026-09-17-v1.8.0-ergo-restyle-design.md)（原 `prototypes/v1.4.0-redesign/` 五轮 HTML 稿已清理，定稿结论以本文为准）

## 问题与目标

前端三端功能已全，视觉语言是做功能时顺手定的。本版对 GUI 与 TUI 做设计主导的整体重做：先 HTML 定方向，再实现。不改 kernel、事件协议与既有功能语义。

## 决策

五轮用户反馈收敛为：

| 项 | 定案 |
|---|---|
| 范围 | GUI + TUI 全部重做；CLI 不动 |
| 视觉参考 | GUI 参 Codex / Claude Desktop；TUI 参 opencode |
| 主题 | 10 套（后定 3 浅 7 深），值取官方定义源；对比度过闸 |
| GUI 侧栏 | 三段固定：功能区 / 项目分区 / 独立对话；项目各自成区挂会话 |
| 新建会话 | 项目头 `＋` 继承项目目录，不重选文件夹 |
| 指标 | `.cz-meta` 5 形态可切（text/num/bar/dots/off），设置可固定 |
| TUI 首页 | 垂直居中、限宽 74ch，信息不删只重排 |
| 交付 | 设计稿定稿后再实现 |
| 状态显示 | 中文界面下配置必须完整 |

不做：kernel/契约改动、CLI 重设计、设计稿阶段定死实现栈。

## 设计

设计 token 单一源 `tokens.css`，`[theme="<id>"]` 切换。槽位：`--bg-base/panel/element/inset`、`--text/mut/faint`、`--border/strong`、`--accent/hover/soft/text`、`--ok/warn/err/info`、`--code-bg`。字阶 `--fs-11..18`，圆角 `--r-4..14`，间距 `--sp-1..6`。

第四轮定案 10 套主题（历史 id，v1.8.0 已重编）：

| id | 名 | 谱系 | 明暗 |
|---|---|---|---|
| `paper` | 宣 | Flexoki Light | 浅 |
| `dawn` | 曦 | Rosé Pine Dawn | 浅 |
| `latte` | 瓷 | Catppuccin Latte | 浅 |
| `sumi` | 墨 | Kanagawa Wave | 深（默认） |
| `mocha` | 檀 | Catppuccin Mocha | 深 |
| `moon` | 霄 | Tokyo Night Moon | 深 |
| `nord` | 峡 | Nord | 深 |
| `forest` | 苔 | Everforest Dark medium | 深 |
| `clay` | 陶 | Gruvbox Material | 深 |
| `rose` | 黛 | Rosé Pine | 深 |

对比度闸门 11 色对 × 10 套 = 110 项，正文 ≥7:1 且 ≤19.5:1，次级 ≥4.5，弱化/强调/语义 ≥3。

GUI 界面清单：主会话、欢迎首页、设置（8 分组含状态显示 22 项全中文）、改动/差异、项目管理、MCP、插件、主题画廊。

侧栏结构：品牌 + 分体新会话按钮 + 搜索；固定功能区（主页/项目/改动/MCP/插件）；项目分区（每项目可折叠，分区内挂该项目会话，按日期分组）；独立对话只放不绑项目的会话；页脚用户与设置。

新建会话归属：项目头 `＋`、分区内旧会话、顶部 `＋`（当前项目）、`⌄` 菜单选位置。只有「打开新文件夹」需选目录。

指标 5 形态：

| 形态 | id | 呈现 |
|---|---|---|
| 文字 | `text` | `tok 34.2k · 命中 38%` |
| 数值 | `num` | `上下文 34.2k/128k · 缓存命中 38%` |
| 进度条 | `bar` | 细长条 + 百分比（默认） |
| 点阵 | `dots` | 十格方块填充 |
| 关闭 | `off` | 不渲染指标 |

状态型标签恒为文字。设置 › 状态显示 4 组 22 项（形态、位置、11 个信息开关、数值格式）。

TUI：启动首页居中 74ch；会话主界面 opencode 式工具树；`/theme` 10 套；`/shell` Windows 宏（pwsh/powershell/cmd/git-bash）。

## 边界与不变量

1. kernel 核心零改动；展示层落 `gui/` 与 `src/apps/tui/`。
2. 密钥渲染只见掩码；GUI IPC 白名单不变。
3. 设计稿为静态 HTML；实施按 plan → 代码 → 回归。
4. D 系 spec 功能语义继续有效；视觉冲突时本 spec 管形态，D 系管语义。

## 与现状的差异

10 套主题已于 [v1.8.0](2026-09-17-v1.8.0-ergo-restyle-design.md) 重编为四段带，再于 [v1.8.1](2026-09-20-v1.8.1-dsh-shell-design.md) 变为「明暗结构槽 + 10 accent 配色」。当前 id：`sumi/slate/vesper/nord/ash/snow/sand/lotus/latte/paper`。侧栏三段与指标 5 形态、项目分区、状态显示设置仍有效。组件现为 `gui/src/components/v4/`。
