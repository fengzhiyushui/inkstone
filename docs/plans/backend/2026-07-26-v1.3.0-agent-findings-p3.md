## 结果

**#7 命令策略双层**：`src/security/command-policy.js` 的 `classifyCommand(argv)` 返回 `safe | dangerous | forbidden`，纯函数零依赖不 throw。归一化 `argv[0]` → basename → 小写 → 剥 `.exe/.cmd/.bat/.com`。清单硬编码于设计 §3.3：

- forbidden = `format` / `mkfs*` / `diskpart` / `bcdedit` / `dd`
- dangerous = 删除类（`rm`/`rmdir`/`rd`/`del`）、系统级（`shutdown`/`reg`/`sc`/`schtasks`/`taskkill`）、`curl`/`wget`、`npm` 且 argv 含 `publish`、`git` 且 `push` 且含 `--force`/`--force-with-lease`/`--delete`、包装 shell（`bash`/`sh`/`zsh`/`dash`/`cmd`/`powershell`/`pwsh`）、解释器带执行参数（`node`+`-e|--eval`、`python`/`python3`+`-c`、`ruby`+`-e`、`perl`+`-e`）

shell / git 工具经 `resolveCategory` 映射：forbidden → `"destructive"`，dangerous → `"execute_dangerous"`，safe → 现网默认。git 的 GIT_READ_OPS 维持 `"read"`。`runProcess` spawn 前对 forbidden 不 spawn，返回策略拒绝（形状同 `spawnErrorResult`，message 注明 `command policy: forbidden`）。审批 summary 带 argv 预览（截断 120 字符）；`event-contract` 的 argHint 读 `call.params`，`ARG_KEYS` 增 `"argv"`，数组值 join(" ")。

**#8 语义降级可观测**：`context:semantic_degraded { reason }` 在 degraded 首次翻转处 exactly-once，reason 为 `error.message` 截断约 200 字符。删除 `config.js` 的 `languages` 键与 `normalizeLanguages`（含旧键配置仍可加载且键消失）；删 `wasm-tree-sitter-provider.js` 的死 `tsx` 条目与 `tree-sitter-tsx.wasm`（`.tsx` → `ts` 映射保留）。

**#9.6 删 GUI 休眠层**：删除 `gui/renderer/` 整目录（app.js、event-adapter.js、workbench-state.js、index.html、style.css）与 2 个对应测试；`gui/main.js` 缺 renderer-dist 且无 dev URL 时 `dialog.showErrorBox` + stderr 提示先 `npm run build:renderer` + 非零退出。`workbench-state.test.js` 保留（import ESM 副本）。

## 关键决策 / 遗留约束

- 命令清单硬编码于 `src/security/command-policy.js`，不开用户配置面，不接 trust-store「总是允许」。
- 高危在 auto 与 full-auto 均 ask；禁止在所有档位 deny，且不可被审批缓存放行。引擎零改动：未知类别 → `matrix[category] || "ask"`，`"destructive"` 在 decide() 最前端 deny，先于审批缓存。
- `runProcess` 兜底仅拦 forbidden，dangerous 不在该层拦，保护 test 嵌套回路。
- 不改 `agent-runtime.js` 的 `send`/`approve`/`interrupt` 语义、事件序、审批协议 `decisions` 数组。
- 不做 #9.3 / #10。粘性降级、`select()` 返回 null、文件级回退全部不变。成功路径无降级事件且 `context:symbol_indexed` 照发。
- 发布时 `package.json` + `package-lock.json`（×2）+ `src/theme.js` + CHANGELOG → `1.3.0`。中文 conventional commit，禁止 `Co-Authored-By`。
