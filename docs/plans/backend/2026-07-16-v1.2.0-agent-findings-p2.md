## 关键决策 / 遗留约束

- 不改 `agent-runtime.js` 行为路径；不改 `send`/`approve`/`interrupt` 语义与事件序。
- 不改 change-store 存储正文；不做 #8 / #9.3 / #9.6 / #10。
- 超时是软预算：跳过慢文件继续搜，metadata 如实上报，不把慢文件当成失败。
- shell **不**放行代理 env，**不**做命令白名单。安全双件只做 TDD 落在 `grep.js` 与 `shell-policy.js`。
- 条目无运行时耦合，可分 commit；维护者要求「版本完成后再一并提交」时，各 Task 的 commit 步改为暂存，收口 Task 一次提交。
- 中文 conventional commit，禁止 `Co-Authored-By` trailer。
- #8 / #9.3 / #9.6 / #10 仍挂账，分别由 v1.3.0 / v1.6 覆盖。
