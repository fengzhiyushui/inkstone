# Phase 4: GUI / Electron — Implementation Plan

- 类型：路线图
- 日期：2026-05-30
- 状态：已完成
- 关联：[CHANGELOG](../../CHANGELOG.md)、[Phase 0](2026-05-29-phase-0-kernel-foundation.md)、[Phase 3](2026-05-30-phase-3-experience.md)

## 目标

做出可运行的 Electron 桌面端：三层渐进披露（Surface → Context → Control）、安全 IPC 隔离、接入 Agent Kernel。

## 结果

Electron 主进程托管 kernel，preload 经 `contextBridge` 暴露白名单 IPC。renderer 原为 vanilla HTML/CSS/JS 无构建步骤，UI State Adapter 把 kernel 事件转成各层视图模型。Tech stack：Electron 30+、Node ≥ 20、Phase 0–3 kernel 模块。

三层信息架构：

- **Surface Layer**：默认聊天视图。
- **Context Layer**：agent 工作时自动展开。
- **Control Layer**：计划/权限审批。

IPC 白名单覆盖：

```text
agent:send      -> kernel.agent.send(message, opts)
agent:approve   -> kernel.agent.approve(id, decision)
agent:interrupt -> kernel.agent.interrupt()
session:timeline-> kernel.session.getTimeline(count)
context:snapshot-> kernel.context.getSnapshot()
model:usage     -> kernel.modelProvider.getUsageStats()
```

主进程动态 import ESM kernel；kernel 未就绪时 IPC 返回 `{ error: "Kernel not ready" }` 而非抛崩。窗口 `webPreferences`：`nodeIntegration: false`、`contextIsolation: true`、`sandbox: true`。

File structure（V1 落地）：

```text
Create:
  gui/main.js            — Electron main process (kernel + IPC)
  gui/preload.js         — Context bridge (secure IPC)
  gui/renderer/index.html
  gui/renderer/app.js    — App controller + UI State Adapter
  gui/renderer/style.css — Styles (3-layer transitions)
  gui/package.json       — Electron deps + scripts
```

后续演进：v1.3.0（#9.6）删除休眠的 `gui/renderer/` 层，改为要求 `npm run build:renderer` 生成 `renderer-dist`，缺构建产物时 `dialog.showErrorBox` 报错。GUI 现以 React 渲染层（`gui/src/`）+ `gui/main.js` / `gui/kernel-host.js` 为主，kernel 入口改为 V2 的 `createKernel`。构建命令 `npm run build:gui` / `npm run gui`。

## 关键决策 / 遗留约束

- 安全 IPC 隔离是硬约束：renderer 无 Node 权限，一切经 preload 白名单方法。
- 三层披露是信息架构，不是三套独立页面；Context 层随 agent 工作状态自动展开，Control 层处理计划/权限审批。
- 主进程动态 import ESM kernel，兼容 `type: "module"` 的内核。
- kernel 未就绪的 IPC 调用返回 `{ error }`，不抛崩主进程。
- UI State Adapter 把 kernel 事件转视图模型，renderer 不直接依赖内核内部结构。

## 验证

V1 集成测试与手工启动 `electron .`。当前对应入口：`gui/main.js`、`gui/preload.js`、`gui/kernel-host.js`、`gui/src/`。构建要求见 `npm run build:gui`；未构建态报错路径在 `gui/main.js` 加载决策分支。

## 任务覆盖（as-built 映射）

Task 1 Electron Scaffold + Kernel Integration（gui/package.json、main.js 动态 import kernel + IPC 白名单、preload.js contextBridge）→ Task 2 三层 UI（Surface 聊天视图、Context 自动展开、Control 审批）→ Task 3 UI State Adapter（kernel 事件 → 视图模型）→ Task 4 集成验证。安全 IPC 隔离贯穿：`nodeIntegration: false`、`contextIsolation: true`、`sandbox: true`。
