## 一、背景与定性

v1.19 系列是**「架构收敛与全栈精简优化专项」**，基准版本 `1.18.0`，本地分支 `v1.19`。

核心原则：**在不削减任何核心功能、且不破坏对外契约的前提下，大范围清理历史冗余与重复实现。**

- **功能不削减**：一核三端、多智能体编排、事务回滚、跨进程恢复、完整 MCP v2 全量保留，任何一项不得因精简而缩水。
- **对外契约不破坏**：`createKernel()` 门面、`send` / `approve` / `interrupt` 语义、事件名与发布顺序、配置键、`.deepseek-code/` 存储形态、CLI / TUI 命令面、`window.deepseek` IPC 白名单一律不变。
- **精简对象是死代码、双轨遗留、重复实现与文档冗余**，不是功能面。
- **全部改动按「纯重构」定级**：行为等价优先，测试基线只增不减，每步独立提交可单独回退。

## 三、验收标准

1. **功能不削减**：一核三端（CLI / TUI / GUI 共用单内核）、多智能体编排（Planner / Worker / Reviewer / 并行写隔离 / 回合循环 / 跨进程恢复）、事务回滚（edit transaction + 脏工作区 + force）、跨进程恢复（paused turn / journal / Recovery Center）、完整 MCP v2（dual-era / Streamable HTTP / annotations 治理 / resources / OAuth / 诊断 / MRTR）全量保留。
2. **对外契约不破坏**：见「背景与定性」契约清单；导入路径更新不得改变任何公开签名、事件名或错误码。
3. **全量测试 100% 通过、零跳过**：测试基线只增不减，`npm test` 无 skip / todo。
4. **门禁四项全绿**：`npm run check`、`npm test`、`npm run build:gui`、`git diff --check`。

## 四、风险与回滚

| 风险 | 影响 | 对策 |
|---|---|---|
| 导入路径更新遗漏 | 运行时模块解析失败 | 每步独立提交；门禁四项全绿才进入下一步 |
| 双轨模块行为不等价 | 精简后功能缩水 | 以既有测试为判据，基线只增不减；先补刻画测试再删实现 |
| 文档整合丢信息 | 决策史不可追溯 | 历史计划压缩为归档表 + git 历史双保险；规格只合并不删事实 |

全部改动均为**纯重构**，风险集中在导入路径更新；任一门禁失败即回退该步（每步独立提交，可单独 revert）。
