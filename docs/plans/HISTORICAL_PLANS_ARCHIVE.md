- **原始逐步计划在 git 历史**：pre-v1.19 的 `main` 分支上 `docs/plans/{roadmap,backend,frontend,architecture}/*.md` 仍可查（`git log --diff-filter=D --name-only`，或 `git show <pre-v1.19 提交>:docs/plans/backend/xxx.md`）。

- **「计划」列 = 原文件名去掉 `YYYY-MM-DD-` 前缀**，日期单列；两列拼回即完整原文件名。
- 63 条全部在档、无遗漏。文中版本号、默认值、契约名、事件名、测试计数均为**当时落地口径**，可能已被后续版本修订。
