# v1.8.1 壳层重构（DSH 参照 · β 路径）实施方案

- 类型：实施计划
- 日期：2026-09-20
- 状态：已完成

## 目标

按 DSH 设计事实重做 Electron 壳层：三列布局、token 中性阶梯、侧栏与会话页、右栏 dock、设置模态。全量搭建设计事实，零引用 DSH 代码。

## 结果

B0–B4 五层已实现（`feat/v1.8`，合入 main / 打 tag 由维护者执行）。基线 `main @ f68ea19`（v1.8.0）· 1107 单测。spec §4.0 总原则已定：全量搭建设计事实，零引用 DSH 代码，与现有前端结合适配。

### B0 · 壳层骨架（B1–B4 依赖）

接口：`computeColumns` / `clampWidth` / `clampRightbarWidth` / `SIDEBAR_MIN` / `SIDEBAR_MAX` / `RIGHTBAR_MIN` / `RIGHTBAR_MAX`；`AppFrame` 三列 grid + `DragHandle`。

- **B0.1 零 DSH 引用守卫**（先于一切）：单测扫描 GUI 源，禁止混入外部设计源码或标识。
- **B0.2 列宽求解纯函数**：`gui/src/state/columns.js`。夹紧、隐藏侧栏、右栏开合时的默认宽（约 viewport 45%）均可单测。
- **B0.3 窗口与首帧**：主进程窗口尺寸 / 最小宽、首帧无闪烁；`gui/src/state/layout.js` 保留响应式辅助。
- **B0.4 AppFrame + 拖拽**：`gui/src/components/v4/AppFrame.jsx` 三列 grid（`sidebar | center | rightbar`），`DragHandle.jsx` 拖拽改宽并在 end 持久化到偏好（`sidebarWidth` / `rightbarWidth`）。

### B1 · token 重铺（C 变体）

- **B1.1 闸门口径先改**：`theme-contrast` 从 110 对改为 structure 2 groups × 7 + accent 10 × 4 = 54 rows 全过；先跑到失败再改 token。
- **B1.2 重写 `tokens.css`**：中性阶梯与 accent 槽位对齐设计取值。
- **B1.3 `theme.css` 别名块 + 派生量**：`[theme]` 别名与 hover / soft / inset 等无独立槽位的派生量。

### B2 · 侧栏 + 会话页

- **B2.1 滚动条 + 超椭圆**：全局 `gui/src/styles/scrollbar.css` 与圆角体系，零功能风险。
- **B2.2 侧栏**：`gui/src/components/v4/Rail.jsx` + `Rail.module.css`。功能区、项目 MRU / 会话分组、新建议话、打开文件夹、主题 / 语言、页脚收放与设置。
- **B2.3 会话页**：`ChatView.jsx` + `SessionHeader.jsx` + `ChatView.module.css`。消息流、事件卡、`chatTab`（chat / trajectory）。
- **B2.4 composer**：`Composer.jsx` + `Composer.module.css`。内嵌状态行（`MetricsLine`）、发送 / 中断。

### B3 · 右栏 dock

- **B3.1 文件树纯函数**：`gui/src/state/file-tree.js`、`file-filter.js`（先测）。
- **B3.2 dock 状态**：`DOCK_TABS = ["plan", "files", "changes", "recovery"]`；`dock_tab_changed` 等 action（先测）。
- **B3.3 Dock 容器与面板**：`Dock.jsx` + `panels/{PlanPanel,FilesPanel,ChangesPanel,RecoveryPanel}.jsx`。右栏宽 < 300 时不渲染，避免盖住主区。

### B4 · 设置模态 + 收口

- **B4.1 设置模态**：`SettingsModal.jsx` + `Settings/{Settings,Form,Appearance,ModelAccess,StatusDisplayPanel}.jsx`；分组来自 `settings-schema.js`（general / appearance / statusDisplay / api / model / limits / orchestration / context / experience / about）。
- **B4.2 守卫与冒烟基线重做**：css-vars / dom-contract / theme-pins 对齐新结构；`gui-smoke` 截图链更新。
- **B4.3 版本与文档**：四处版本、CHANGELOG、docs 索引。

布局事实：主视图 `home` / `chat` / `projects` / `mcp` / `plugins`；设置走模态。快捷键：`N` 新建会话、`B` 侧栏收放、`J` 右栏、`,` 设置、`Shift+L` 明暗切换。敏感提醒模态独立于审批（`gui:sensitive_notice` → `SensitiveNoticeModal`，答复 `respondSensitive`）。切换项目重建 kernel；打开会话走 session-index。

## 关键决策 / 遗留约束

- 零 DSH 代码引用；设计取值只读参照 spec 与附录，不复制外部实现。
- 列宽被挤掉时不可绝对定位盖住主区。
- 不碰 kernel；IPC 白名单与密钥掩码不变；不引入新运行时依赖到主包。
- 每层一个完整提交；提交信息不带 `Co-Authored-By`。
- 状态行字段与偏好键沿用 `statusDisplay` / `railCollapsed` / `sidebarWidth` / `rightbarWidth` / `dockTab` / `glass` / `lastDark` / `lastLight`。
- 版本口径四处同步（`package.json` / lock / `theme.js` / `gui/src/App.jsx`）。
