## 目标

在不改 DOM 合同的前提下重铺 10 主题 token、加固对比度闸门、做壳层视觉与卡片两段式，形成 v1.8 工学皮肤。P0–P3 四层各一个提交；是 v1.8.x 视觉基线。

## 结果

已实现（2026-09-20），测试数 1089 → 1107。每层五项准入全绿后推 `feat/v1.8`（`feat(v1.8.0-p0)` … `-p3`）。

### P0 · tokens 地基

10 主题变为四段带（dark 3 / dim 2 / tint 2 / light 3）。完成后界面可无感变化，只有主题列表与 token 源更新。

接口（P1/P2 依赖）：

- `gui/src/state/themes.js` 导出 `GUI_THEMES`（10 条，顺序即 UI 顺序，每条 `{ id, name, tier, group, family }`）、`themeLabel(id)`、`isLightTheme(id)`（语义：`group === "light"`）、`isDarkTheme(id)`、`TIERS = ["dark", "dim", "tint", "light"]`、`themesByTier()` → `{ dark, dim, tint, light }`。
- `gui/src/state/workbench-state.js` 状态新增 `lastDark`（默认 `"sumi"`）、`lastLight`（默认 `"latte"`）、`glass`（默认 `true`）；新 action `glass_changed`；`theme_changed` 同步 lastDark/lastLight。
- `gui/kernel-host.js` 偏好白名单新增同三键。
- `scripts/check-theme-contrast.mjs` 导出 `checkThemes(css) → { ok, rows:[{ theme, pair, value, min, max, pass }] }`、`contrastRatio(fg, bg)`。

主题 id 与族源：sumi 墨（Kanagawa Wave）、slate 玄（Tokyo Night Storm）、vesper 烬（Vesper）、nord 峡（Nord）、ash 灰（Zenburn）、snow 霜（Nord Snow Storm）、sand 沙（Gruvbox Light Soft）、lotus 荷（Kanagawa Lotus）、latte 瓷（Catppuccin Latte）、paper 宣（Flexoki Light）。

退役 id 静默迁移（`LEGACY_THEME_MAP`）：`night→sumi`、`day→latte`、`dawn→lotus`、`mocha→sumi`、`moon→slate`、`forest→ash`、`clay→vesper`、`rose→sumi`。

P0 任务顺序：

1. **P0.1 闸门脚本**（先于取色）：`contrastRatio` 复现历史值；`checkThemes` 对 `tokens.css` 出 10×11=110 行且全过。执行者在 P0.2 前须亲跑 `node scripts/check-theme-contrast.mjs` 看到 110/110。
2. **P0.2 重写 `tokens.css`**：六套新块色值见原方案附录 A（自官方色板派生，双人独立复核；闸门脚本是判据，附录是起点）。
3. **P0.3 主题 id 选定点约 9 处一次改齐**：退 6 动 6 必须原子，否则 `=== 10` 断言红。
4. **P0.4 三端主题 id 单源守卫 + DOM 合同守卫**（`theme-pins.test.js`、`dom-contract.test.js`）。

## 关键决策 / 遗留约束

- DOM 与类名冻结（spec §5）；P0 加字符串守卫，禁止顺手改类名。
- 为 β 留门：新类名只取映射表；`shell.css` 新规则只追加末尾独立区块（后续样式已迁回 `theme.css` 与模块 CSS）；派生变量进 `theme.css` 的 `[theme]` 别名块；偏好键定名 `lastDark` / `lastLight` / `glass`。
- 视觉规则：字号 ≥11px 且落在 `--fs-11..18`；图标只用 `lucide-react`（12/14/16）；零 emoji；文案全进 `strings.js` zh/en；可点击元素 `<button type="button">`；无 `transition: all`；新增动效 ≤.25s 且 `prefers-reduced-motion` 关。
- 不得触碰 kernel 八目录（`src/core src/deepseek src/tools src/edits src/sessions src/context src/security src/workspace`）。
- 每层五项准入：`npm test`、`npm run check`、`cd gui && npm run build:renderer`、`DEEPSEEK_CODE_GUI_SMOKE=1 node --test tests/e2e/gui-smoke.test.js` 输出 `GUI_SMOKE_READY`、八目录 diff 为空。
- 分支在主 worktree 开 `feat/v1.8`；不推 main、不打 tag。
- 前置：v1.7.2 必须先合入（P2 依赖 assistant 回复入流）。
- 遗留：P1 收口与 P3 的人工目视截图比对由维护者完成；基线已入库。
