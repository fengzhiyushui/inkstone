# v1.4.0 前端重构实施方案（GUI / TUI 整体重做）

- 状态：已完成

## 目标

把 GUI 从 VS Code 式 IDE 改成会话优先工作台，TUI 补首页/主题/终端切换，并建立项目 MRU 与会话列表数据层。

## 结果

### 现役形态

GUI 走 React 19 + Vite 7 + Electron 30 + Monaco + lucide。`gui/src/App.jsx` 路由主视图 `home` / `chat` / `projects` / `mcp` / `plugins`；右栏 Dock 为 `plan` / `files` / `changes` / `recovery`；设置为全窗模态。主题为 `gui/src/styles/tokens.css` 的 10 套 `[theme]`：sumi / slate / vesper / nord / ash / snow / sand / lotus / latte / paper。

会话主界面：消息流（用户气泡 / agent 排版）、事件卡、composer 内嵌状态行、欢迎首页（快捷入口 + 最近会话）。指标状态行支持 text / num / bar / dots / off 多形态，读偏好 `statusDisplay`。

### 数据层

| 模块 | 职责 |
|---|---|
| `src/apps/project-registry.js` | 全局项目 MRU，`~/.deepseek-code/projects.json`，原子写、路径校验、当前项目置顶 |
| `src/apps/session-index.js` | 枚举 `<root>/.deepseek-code/v2/sessions/proj_*/sess_*.jsonl` → `{ id, mtime, 首条用户消息摘要, 事件数 }`，按项目分组 |

宿主 IPC：`projects:list/add/switch`（switch = 以新 root 重建 kernel）、`sessions:list/open`（open = 时间线回放）、主题与偏好读写。

### TUI

`scripts/gen-tui-theme.js` 从 tokens 生成 `src/apps/tui/theme-palette.js`（生成物入库，运行时零依赖）。painter 多屏 home/chat；启动进 home（垂直居中、74ch 限宽、单行 meta、居中输入框、最近会话）。`/theme` 10 主题写 `tui-prefs.json`；`/shell` 四宏 pwsh / powershell / cmd / git-bash，缺失项灰显，状态栏 `sh:` 标识。会话流按 v4 精修角色前缀、引导线工具树、审批块间距。

## 关键决策 / 遗留约束

- GUI 技术栈不换，不引 UI 组件库；Monaco 服务 diff，node-pty 留宿主能力。
- 渲染层原地重写，宿主层只增不推倒；禁止两套渲染层并存。
- `tokens.css` 唯一 token 源；TUI 用生成的 256 色近似，含 16 色降级；`NO_COLOR` 全禁路径保持。
- kernel 八目录零改动；安全不变量不动（密钥掩码、IPC 白名单）。
- MCP / 插件只做概念预览，不接运行时。
- 会话「打开」保底为时间线回放 + 「续聊」开新会话，不为此改 kernel。
- 项目切换 = 重建 kernel：先 interrupt + flush + unsubscribe，再 `disposeAndRecreate(root)`；切换期 UI 上锁。
- 旧版 `~/.deepseek-code/sessions/` 遗留数据不迁不删。
- 出界：kernel 修改、MCP 功能语义、新语言、CLI 重设计、多窗口、会话跨项目移动。

- TUI：`tui-smoke` 扩首页断言；NO_COLOR / 非 TTY 退化保持。
